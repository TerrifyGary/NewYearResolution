# 制服地圖校名整併與夏季款式 — 2026-11-11

## 本輪結果

- 移除所有學校制服 SVG 內可見的校名小字；卡片校名、圖片替代文字與 SVG `<title>` 保留，方便辨識與無障礙閱讀。
- 教育部115學年度高中職名錄保留506個校碼。逐頁讀取 [Uniform Map 台灣高校分類](https://uniform.wingzero.tw/zh-TW/schools/tw/categories/1) 的20區、25頁，共562筆來源校名。
- 475筆來源依同地區校名或明確別名對應既有校碼；87筆未對應資料分開保留，合計 **593筆可搜尋學校身分**，另保留364個來源別名。562是來源站選項數，593是本機整併身分數，都不等於現行可招生高中數。
- 原76校的插畫皆找到來源站校名對應；這是**學校身分核對**，不是76套款式全部重新取得校方證實。已有校方來源的設計繼續優先採用。
- 新增24校／24款夏季女生制服，累計 **100校／129款**。來源分為66校校方、3校媒體、3校其他既有參考、10校制服地圖文字、18校制服地圖示意圖。後兩者分開標示待核對。
- **406校及尚未確認的性別款式仍未繪製。** 圖庫不再用通用服裝填滿待補卡片；這些卡片僅保留校名及查找連結。移除「目前沿用通用插畫，尚未確認這所學校的實際款式。」等文字。遊戲內既有未知款式後備規則仍存在，新完成的對應款式會自動取代該校後備圖；國小、國中既有通用資產未改成未經證實的校服。

## 使用範圍

[本機圖庫](http://127.0.0.1:5173/uniform-library.html) 的「學校字典（含別名與來源校名）」可搜尋全部593筆；其他篩選繼續針對506校高中職圖庫。搜尋「達人女中」「竹北」等來源名稱會對應既有校碼。臺北立人與臺中立人、公私立大同、國立／縣立苑裡不合併。

未對應資料包含已停辦學校、大專校院、外僑學校及個別學部／校區；不推定學制、性別限制、成立或停辦年份，也不直接放入高中分發。像國立高雄餐旅大學與高餐附中、三重高中國中部與高中部、葳格國際部與一般學部都保留個別來源身分。和春技術學院被來源站放在臺北分類，本機只記為 `sourceRegion`，沒有把它當成已驗證校址。停止辦學標記亦明示為來源站說法，不能據此替代適用年度的教育部招生資料。

本輪沒有更動學校候選池、校碼、存檔格式或RNG；校名查詢是純讀取函式，整併資料不匯入遊戲模擬 bundle。既有存檔可繼續用同一校碼取得新完成的插畫。完整舊校名適用年代與新增學校招生資料仍待官方補證。

## 夏季款式審閱

使用來源站一次「夏季」查詢的前10頁結果，跨語系去重後有57筆款式，另跟進1個現行款連結；共58筆候選、56筆成功讀取。兩筆在來源回傳429時停止，未繞過限制。此搜尋不是全站款式普查；來源站的562筆校名不保證每筆都有制服圖片或介紹，例如中崙高中本輪頁面的制服區仍是空白。

審閱保留27筆已對應插畫、14筆既有來源優先、6筆其他學部／學制、6筆運動服、2筆舊款、1筆科別限定及2筆受限未查。27筆對應插畫包含3筆前批款式，故本輪實際新增24校。鹿港改跟進來源所列現行灰藍細紋上衣／灰色褲裙（uniforms/243），沒有採舊版（uniforms/233）；來源自己表示啟用年不確定，沒有將2006當成已證實年份。君毅高職部、樹人幼保／美容科與運動服不套用成全校一般高中夏季制服。

來源站標示圖片為AI示意。本輪依使用者希望優先採用 Uniform Map 的要求，對只有示意圖的可用學校，觀察配色與輪廓後以本專案 SVG 系統重繪，來源標為 `secondary / third-party-illustration`，描述以「參照制服地圖示意」開頭；不把這些圖當真實照片或官方校服史實。文字來源使用 `third-party-description`。兩者的出版年份均保留null，查閱日另外記錄。素材包不包含來源站人物圖片、校徽、浮水印或複製圖；色票與細節是簡化詮釋，仍需校方資料核對。

## 檔案與重建

- `packages/world-data/src/uniform-map-directory.json`：562筆來源校名與逐頁查閱清單。
- `uniform-map-aliases.json`：人工對應；其餘只做標準校名字樣／地區的唯一精確比對，不用模糊比對自動合併。
- `school-name-catalog.json`、`school-name-directory.ts`：593筆資料、來源類型、別名、純讀取查詢及插畫校名核對。原本國小／國中 `school-directory.ts` 保留不變。
- `uniform-map-summer-review.json`：58筆候選的查閱、採用或排除結果，僅保留標題、連結與本專案審閱備註，沒有整頁文章與照片。
- `scripts/assets/school_directory.py`：完全離線重建整併資料；`npm run uniforms:build` 同時重建129張SVG、圖庫及字典／審閱CSV。
- 圖庫產物放在 `apps/web/public/illustrations/uniforms/`，可靜態部署至GitHub Pages，沒有新增服務或API。
