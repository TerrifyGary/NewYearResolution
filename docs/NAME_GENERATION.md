# 姓名與角色性別一致性

更新：2026-11-11。

## 問題與修正

原先所有角色共用男女混合的80個名字，與 `gender` 獨立抽取；交往／直接成家的對象還會在取名後才覆寫性別，因此會反覆生成「俊傑」等傳統偏男性的名字搭配女性角色。畫面原本讀取的是已儲存的性別，問題在生成流程。

新角色先確定性別，再從對應偏好與中性姓名池抽名：27個偏男性、39個偏女性、14個中性名字。中性池兩邊皆可使用。這是命名風格設定，不是規定名字只能由某種性別使用，也不代表觀察到的人口頻率；玩家手動替孩子取名仍可自由選字。

- 玩家、出生／領養孩子使用各自已生成的性別。
- 新原生家庭中的「父親／母親」分別以男性／女性角色建立後取名；不更改既有家庭紀錄。
- 新交往對象、直接生成的成家對象，使用玩家喜歡的性別建立後取名；姓名不決定性向。
- 已交往的角色成家時保留原姓名與性別，不因玩家目前的性向欄位而重新指定性別。
- 孩子六個建議名字從對應池不放回選取，保持六個不同建議；取名畫面顯示孩子性別（繁中／英文）。

## 資料邊界

參照內政部戶政司《112年全國姓名統計分析》，表五十一「前一百大常見名字排名與人數按性別分」把俊傑列在男性常見名字。資料基準2023-06-30、出版2023年10月，2026-11-11查閱。這支持此次典型名字的交叉核對，不能用來斷定任何現實人物的性別。

來源：[官方報告](https://www.ris.gov.tw/documents/data/5/2/112namestat.pdf)、[官方出版品頁](https://www.ris.gov.tw/documents/html/8/5/241.html)。完整PDF較大，本次以搜尋引擎可讀的官方表格摘錄交叉核對，未匯入完整報表。其餘池分類為作者設定，不宣稱已逐名統計校準；姓氏頻率與出生年代命名趨勢仍待另外接入。

## 確定性與舊存檔

不新增性別判定欄位、不改schema版本、不從名字推斷性別。姓名抽取維持原有世界RNG呼叫數；對固定種子的回歸案例，出生地、玩家性別／性向、初始屬性、自主年齡與RNG保持相同。新規則下固定種子重播仍一致，但新生成角色的名字及父母角色性別會採新流程。

孩子建議名字使用獨立hash，不改世界RNG；讀取、切換語言或重看不會重新擲骰。尚未命名孩子可看到更新後建議，已確認的名字不會被重抽。

所有已記錄人物姓名、性別、過往記事、卡片與存檔保留。例如舊存檔的女性「江俊傑」仍保持原紀錄，不直接替玩家改名或改性別。玩家自訂的同名角色亦不會被禁止。

## 驗證

測試包含可重現的女性俊傑案例、500個不同出生年份／種子的玩家與父母、四種玩家性別／對象性別組合、直接成家與交往後成家、建議不重複及不改RNG、自訂名字、舊存檔原樣保留，以及取名UI繁中／英文性別顯示。2026-11-11 驗證：`npm test` 共16個檔案、265項測試通過；`npm run build`通過。另對照修正前保存的4個種子案例，初始玩法參數與世界RNG全部一致。
