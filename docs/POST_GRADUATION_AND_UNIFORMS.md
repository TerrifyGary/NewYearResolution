# 畢業後自動選擇、收手求職與高中夏季制服

更新：2026-11-09。以下記錄本次實作；舊存檔的學籍、骰點、帳目及種子保持原樣。

## 自動選擇

原先畫面把「沒有在學、也沒有工作」當成沒有階段，因此大學畢業後、待業或結束營業時會停用播放按鈕。計時器還把退休者算成工作階段，與按鈕判斷不同。

現在按鈕與計時器統一呼叫確定性的 `playbackStage`：在學時使用學制；未滿6歲為幼兒階段；成年待業、求職與創業均屬工作階段；退休另有退休階段。未成年升學空檔保留上一學制。換階段仍會關閉自動播放，需要玩家在新階段再按一次。

取名、必答問答／人格故事、背包過重仍會暫停；畫面會說明原因。回答後的結果畫面可自動繼續，到下一個必答問題再停。停止播放、切換階段和離開畫面會清除計時器。播放狀態屬UI，不寫入世界種子或存檔。

## 收手回到職場

- 求職／打工事件遇到經營中的事業，除了保留事業，也可直接「收手結束營業，重新找工作」。維持原安排仍是第一個選項。
- 結束營業停止之後的營運收入，清除負責人職位與工資安排，保留事業本金、歷史損益及帳目，不憑空退回創業本金。
- 接續翌日的職缺選擇。在校學生仍用打工職缺，畢業者用符合資格的全職職缺；錄取保留D20，不直接配發工作。
- 創業當年若11月20日尚未經過，就補入當年的營運回顧；舊存檔已經提前結束營業後，尚未處理的回顧只能略過，不會重啟事業或重算收益。
- 低現金的學生經營者不會每個月被重複塞入不能應徵的打工事件。

`LifeState.business.closedDate` 是選用ISO日期。既有schema7事業沒有這個欄位仍可讀入；新結束日期可保存／讀回。這是遊戲的結束營業狀態，不代表模擬公司註銷、清算或法定資遣程序。跨年翌日求職沿用既有年度排程，年末事件仍可能要等下一年度的求職安排。

## 夏季制服圖庫範圍

使用者確認第一版先做夏季日常制服。圖庫收錄115學年度字典的 **506校**，每校有穩定教育部代碼、名稱、縣市、網站與男女款查詢入口。**名錄完整不代表實樣已全數查證。**

2026-11-09初批 **19校有參考資料、21款原創SVG**；其中15校使用校方文件，1校使用新聞資料，3校使用維基百科。當時其餘487校沿用通用插畫。2026-11-11已擴充為 **69校／97款、437校待補**，最新查找清單見 [UNIFORM_RESEARCH.md](UNIFORM_RESEARCH.md)。有資料學校內未確認的另一款式，也保留通用款，不能視為已完成。沒有確認的學校不生成隨機配色冒充實樣。

有資料學校：北一女、建國、景美、成功、彰化女中、彰化高中、臺南一中、臺南女中、高雄女中、蘭陽女中、花蓮女中、金門高中、家齊、高師大附中、臺北中正、基隆女中、南投高中、新竹光復、松山高中。

北一女採綠上衣、黑摺裙、金黃繡字；建中／南一／金門保留卡其色系；家齊有水手領；基隆女中有格紋；南投有直條紋。這些是配色與基本輪廓的簡化重繪。色票、格紋比例、摺數、校徽、特殊科別、冬季／運動服，以及歷年改款尚未完整復刻。來源年份介於2008–2026，不保證全部適用2026新生或每個歷史年份；遊戲沿用參考樣式，不宣稱歷史服裝考證完成。

圖庫頁 `/uniform-library.html` 可依校名、縣市、資料狀態搜尋、分批瀏覽，保留每校來源連結與年份。遊戲的物品卡、道具檢視依原有schoolId自動選圖；北一女等舊curated ID與教育部ID對應同一款。道具ID、人物性別、學籍、重量、RNG和帳目不變；國小女生吊帶裙保留。不在遊玩故事裡插入圖庫查證警語。

來源與可重建資產：

- `packages/world-data/src/uniform-references.json`：逐校款式、URL、來源類型、年份與查閱日。
- `scripts/assets/uniforms.py`：標準函式庫產生SVG與506校目錄；沒有抓取網站或呼叫生成API。
- `npm run uniforms:build`：重建圖樣與兩份相同目錄（資料包／靜態圖庫）。
- 原始圖片只用於參照，沒有把學生照片、他人插畫或校徽圖檔放入專案。

## 驗證

回歸測試涵蓋：畢業待業與退休的播放、手動問答暫停／恢復、求職與打工收手、首次營運回顧、關店後停止收入、舊回顧失效、結束日期存讀與不重擲／不退本；圖庫涵蓋全部506個代碼、圖檔存在、北一女新舊ID對應、通用款標記及存檔/RNG不變。2026-11-09 執行 `npm test`：15個檔案、250項測試通過；`npm run build`通過。長人生案例保留180年／每年100步的防卡死上限，個別執行時限由40秒調為90秒，以容納新增營運回顧帶來的不同長人生路徑。瀏覽器另確認圖庫搜尋、506校篩選、待補狀態、48→96張分批載入及插畫排版；圖庫重建前後雜湊一致。
