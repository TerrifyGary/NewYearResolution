# 制服地圖／UniForme 查找 — 2026-11-11

接續前批69校／97款，依使用者指定的「Uniform Map 制服地圖」查找其餘437校。網站目前名稱為UniForme 制服誌；本批以公開搜尋索引逐校查找，沒有建立帳號、下載學生照片、呼叫付費服務或批量直接抓站。直接頁面曾回傳429／403，沒有繞過限制。

## 結果與範圍

- 437校均有查找紀錄。230校有明確同名同地區的候選參考頁；207校本次未找到能明確對應的索引頁，不代表網站或現實中沒有該校制服。
- 查找結果先比對地區與校名；同地區同名的國立／縣立苑裡、臺北公私立大同等不得合併。三民高中與三民家商、高餐大與餐旅中學也不互相替代。竹北高中舊名另以校方資料核對到陽明交大附中。
- 本批新增7校／8款：安樂、八斗、臺北育達、稻江護家、三民家商、陽明交大附中（竹北高中）、弘文。
- 累計506校名錄，76校／105款有參考插畫；其中66校採校方文件、3校採媒體、7校採其他參考。7校其他參考中，有4校是本批制服地圖文字，**尚待校方核對**。
- **仍有430校未繪實樣。230個對應參考頁不是230款制服，更不能當作437校已完成。** 搜尋索引不保證完整，目錄／空白／只有圖片的頁面也沒有提供足以確認款式的證據。

## 文字記述與AI示意圖

該站[首頁](https://uniform.wingzero.tw/zh-TW)及[安樂制服頁](https://uniform.wingzero.tw/zh-TW/schools/tw/categories/1/regions/3/schools/126/uniforms/141)說明目前圖片為AI示意，不保證代表真實設計。本批**沒有取其AI圖片當真實照片證據**，只把可讀的服裝文字作為可追溯的第三方記述，原創重繪基本輪廓與配色。

安樂、八斗、臺北育達、三民家商的來源設為secondary／third-party-description；圖庫卡片明示「第三方文字 · 待校方核對」，備註說明圖片政策。這些有來源的詮釋圖不能稱為官方已證實制服。臺北育達另有[校方2022改版公告](https://www.yudah.tp.edu.tw/event?i=1629)支持海軍藍／洋紅設計方向，但不能僅憑此推定所有細節已核實。三民家商有舊資料裙色差異，沒有消除年度差異或聲稱全歷史一致。

竹北的第三方記述與[學校校規](https://www.cpshs.hcc.edu.tw/resource/openfid.php?id=12948)不同，採後者的藏青連身裙與白圓領，保留差異記錄。弘文採[校方校服沿革](https://www.hwhs.tc.edu.tw/ischool/publish_page/191/?cid=3494)高中部黃上衣，不採國際部白襯衫或國中部藍上衣。稻江護家採[校方轉載新聞](https://www.tcnvs.tp.edu.tw/modules/tadnews/index.php?nsn=229)確認白上衣及鈷藍格裙。來源年份未明的第三方頁面保留null，不把查閱日或自述制服起始年冒充文件出版年。

## 實作

- `packages/world-data/src/uniform-map-research.json`：437筆校碼、校名、地區、查找日、搜尋式、相符頁、人工審閱狀態及來源差異。只保存索引標題與連結，不保存整頁文章或照片。
- `UniformMapLookup`型別與`UniformSchool.reference.evidence`分開表達目錄查找及文字證據；研究檔不匯入遊戲JavaScript bundle。模擬、人物、存檔、學籍與RNG沒有改動。
- `npm run uniforms:build`重建105張SVG、兩份506校圖庫目錄、原487校清單及[本批437校CSV](../apps/web/public/illustrations/uniforms/uniform-map-research.csv)。新增連身裙輪廓與領飾斜紋／格紋，不下載或熱連外站照片。
- [本機圖庫](http://127.0.0.1:5173/uniform-library.html)新增「有制服地圖參考頁」篩選、每校收折的查找結果、獨立CSV下載及4校第三方文字標示。研究清單讀不到時仍可看插畫與翻頁。
- 不在遊戲事件中添加這些查找狀態；來源限制集中於圖庫與文件。
