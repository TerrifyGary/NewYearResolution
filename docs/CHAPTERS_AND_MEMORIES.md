# v0.6：地區、階段、背包與住房

## 已接入

- 出生地從原本四區等機率，改為368鄉鎮市區依戶籍人口加權。**實際成功取得的是2025年底人口23,299,132人，非2026人口**，資料由戶政司 ODRP019/114 四頁7752村里彙總。2026完整人口未取得，不能宣稱已完成2026人口校準；更早出生年也使用此快照作場景基準。
- 國小2609筆／國中740筆現有115學年度快取全部接入，不再只接四個區。加上教育部115高中506筆名錄。中正區8間國小、苓雅區4間國中等依真實可用記錄提供，**不能為湊十間編造學校**。較早年代允許用2026名稱快照作情境，不表示已核實該年代校名及開設。若區內沒有該層級學校，回退同縣市可用真實校名，非聲稱該校位於出生區。原始from年份仍保留，不追改舊存檔的學籍。
- 高中可用全市名錄，臺北／新北互通。名錄包含綜合高中及職業教育學校，完整普通科／各科招生與單一性別限制仍需逐校補齊；不是官方分發。
- 財務帳本僅保留累計資助／自己花費／子女費用摘要及當年度帳目。完整歷史與過往學校成績只在人生年表。
- 右上選目前階段自動選擇，約0.8秒推進一頁，切出該階段停止。可以隨時改回手動。人格題、人格情境、孩子取名、死亡及背包過重會停下；自動選項是依已存RNG狀態索引，沒有UI另擲骰或改變引擎亂數流。
- 幼兒年度目標只保留人際／健康，特殊專長欄小學年齡起顯示。生病家人事件在成年前或尚無外住紀錄時只提供陪伴。
- 每個國小、國中、高中／高職／五專、大學、碩班階段，以及有紀錄的工作／升遷職位變更，有四個不可略過的偏好問題及一段16型傾向情境。四軸組合16型，題目及敘述按班級活動、分組作業、園遊會、分組報告、研究與工作切換。**這是遊戲人格傾向，不是正式MBTI量表或診斷**；另有國小、國中、高中、大學、碩班、換工作與升遷各16段情境，共112段短篇事件，含共同的兩種回應途徑；不是112條長篇分支劇本。既有舊存檔在接下來互動或新年度補安排目前階段，不重寫過去答案。
- 國中11種、高中16種、大學22種新增社團情境，加上相容舊存檔的四種基本社團。新社團才建立對應興趣值；沒有咖啡經驗時隱藏咖啡數值。音樂／體育入學按目前選定方向二擇一，選擇樂器／運動會切換方向；普通以下資源家庭不能選正式音樂班。已取得的樂器物品不因改方向消失。
- 段考新公式：`round(30 + 熟練度×2.2 + D20×1.2)`，最高99分。熟練20、骰1為75分，骰20為98分；不再全部100分。200人參照母體以固定分布函數估算校排，**不是實際校內學生逐一考卷或官方排名**。舊成績不重算，報告存formula2辨識公式。
- 會考標示補齊A++／A+／A／B++／B+／B／C。標準來自官方制度，D20門檻仍是遊戲值，未建立各科實際題數、英聽加權及年度切點。
- 玩家初始有小被被；交換貼紙、尋寶四葉草、出遊照片、告白卡片、課本、制服、畢業簽名制服與紀念冊、持有樂器與運動裝備會進物品欄。每件按類型計重，5公斤提示整理並暫停自動推進；可放下物品。回憶物品不因放下又在下次事件無限重送。舊器材仍是輕量持有模型，部分舊版車輛／裝備未逐件折算重量。
- 物品欄有程式繪製SVG小插畫；制服為通用插畫，**尚未查證各校制服圖案**。沒有把通用圖說成真實校服。死亡後物品頁生成留下物品與年度摘要的小卡，尚無獨立PNG匯出。
- 穩定交往滿3年且成年可討論成家；每次人格階段完成有30%遊戲機率觸發伴侶討論，D20加感情值判定是否繼續，亦可選分手。這是「觸發討論」機率，**不是保證30%實際分手率**。付費約會親密+1，不再+5。
- 上班可選近公司月租12,000或遠處7,000。成家可選市區1200萬／遠處600萬，20%自備款；自籌或富有且留足30萬元的在世父母資助。房價、租金及銀行可貸性皆為遊戲情境。按月分開本金與利息，40年上限並考慮年齡加年限80；未採寬限期。2026後以3年1.775%、第4–6年1.9／2.025／2.15%、其後2.275%的參考利率攤還。**不是核貸承諾或浮動利率預測**，也未建模婚育加額、各銀行徵信、房屋稅費、所有權與婚姻登記資格全部細則。2026前仍使用2%簡化情境，不能稱歷史新青安。
- 深色模式可切換並存在該瀏覽器，不影響遊戲存檔。

## 來源

人口：[戶政司ODRP019/114](https://www.ris.gov.tw/rs-opendata/api/v1/datastore/ODRP019/114)，政府資料開放授權條款第1版。快取population.json保留適用年及說明。

學校：[教育部115國小](https://stats.moe.gov.tw/files/school/115/e1_new.csv)、[國中歷年](https://stats.moe.gov.tw/files/opendata/j1_new.csv)、[115高中](https://stats.moe.gov.tw/files/school/115/high.csv)。高中原始CSV留在world-data/raw。

會考：[官方成績計算](https://cap-rcpet.rcpet.edu.tw/score3.html)，A/B均有加註，勿漏B++與B+。

住房：[國庫署青安3.0說明](https://www.nta.gov.tw/singlehtml/238?cntId=6bcd4dfe5dbd466a9432bd641690eb6c)、[土地銀行方案](https://oi.landbank.com.tw/product/12)。查核日2026-11-09。未來年度沿用基準，實際政策可能改變。
