# 夏季制服逐校查找 — 2026-11-11

本文件保留前批69校／97款紀錄。後續依使用者指定制服地圖的查找與最新76校／105款範圍，見 [UNIFORM_MAP.md](UNIFORM_MAP.md)。

本次接續原本19校／21款，搜尋其餘487校的公開校方網站與文件，補入 **50校、76款原創SVG**。累計 **506校名錄、69校有參考圖樣、97款插畫**；其中64校採校方／政府公開文件，2校採媒體，3校沿用前批次維基參考。**仍有437校未確認實樣**，也有已收錄學校的另一款尚未確認。名錄、搜尋紀錄、候選頁及已繪實樣是不同狀態。

## 查找結果

- 原待補487校皆有逐校搜尋紀錄；Google Sites學校另以所屬學校網域路徑及校名重查，排除其他學校共用主機的結果。
- 439校有本站候選頁，候選頁不保證有制服照片或有效規格。本批50校由人工檢視可支持的配色及基本款式後繪製；其餘389校候選頁仍待查核。
- 48校本次沒有符合本站範圍的索引結果；這不代表該校沒有制服或網路上沒有資料，仍需校方相簿、供應商或其他公開來源補查。
- 排除國中部款式、運動服、冬季服、國際部限定款，以及校方會議附件中引用其他學校的服儀。例：君毅高中部白衫不能套用國中部綠水手服；曉明高中部暗紅裙不能套用國中部淺藍裙；中山女高會議附件中的松山條文不能當成中山款。
- 只有一款資料清楚時只繪該款；其他款沿用通用圖。校規准許褲裙自由選擇時，男女欄位僅為既有查圖介面，不把插畫示例當成新性別限制或招生規則。

## 資料與圖庫

- [逐校款式與來源](../packages/world-data/src/uniform-references.json)：URL、文件年份、查閱日、來源類型、輪廓與配色、備註。未確認文件年份保留null，不能把2026查閱日當作出版年。
- [487校搜尋紀錄](../packages/world-data/src/uniform-research.json)：校碼、搜尋式、候選頁面標題／URL及待核狀態，不保存整頁文章或學生照片。
- [可下載CSV](../apps/web/public/illustrations/uniforms/research.csv)：附UTF-8 BOM，與本機圖庫連結共用。執行 `npm run uniforms:build` 依目前已繪資料更新狀態。
- [本機圖庫](http://127.0.0.1:5173/uniform-library.html)：篩選、搜尋、分批載入；新增收折款式備註、未註年份顯示及CSV下載。
- `UniformDesign` 增加圓領、Polo、領片色、格領、條紋色、同時條紋上衣與格裙等繪圖參數。修正襯衫門襟使用絕對終點、Polo短門襟及短褲接縫；沒有資料的水手領不憑空補滾邊。

插畫是依參考配色／基本輪廓做的簡化重繪，並非精準制服紙樣、色票或歷年復刻。格紋比例、褶數、材質、校徽、細節配件仍有簡化；參考年代不等於2026或所有遊戲年份均適用。此限制集中於圖庫與本文件，不插入遊戲事件。

沒有修改存檔、人物、學籍、RNG、物品重量或模擬引擎；研究清單和生成目錄不匯入遊戲JavaScript bundle。既有schoolId依查圖函式取得新插畫。
