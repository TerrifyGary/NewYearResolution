## 家庭分開與子女照顧

每年提供家庭關係回顧。維持家庭是第一選項及自動模式預設。選離婚後，下一日必須再確認，才更新共同家庭、雙方伴侶連結與交往狀態。既有婚後交往事件也使用同一確認流程，不能從舊的分手選項繞過照顧安排。

子女安排是**簡化的遊戲照顧評估**，不是法院判決或真實離婚程序：

- 保留雙方親子／收養連結，不把孩子視為可切分財產。共同未成年子女一起跟隨主要照顧者，保留雙方監護聯繫，不按性別分配。
- 經濟資源＝非負現金淨額＋六個月工作收入估值；照顧分數同時採用資源（上限30分）、健康、疲勞、可用照顧時間與維持原有住處。分數相同時優先維持原住處。這些權重不是官方裁判公式。
- 另一方另設租屋家庭；孩子住處與主要照顧者一致。每月扶養費以NT$8,000需求估值，按雙方資源比例分擔。支付與收取各記一筆帳，未成年且父母均在世時執行，成年後停止。
- 分開日期、前伴侶、主要照顧者、支付者與每月金額可在家庭欄查看。每月支出繼續依實際同住子女計算。
- 個人現金、債務與既有住宅紀錄保留，尚未實作夫妻剩餘財產差額、贍養費、司法／登記程序、子女意願訪談、共同照顧時間表、搬家費與房屋權利分割。懷孕中的後續親職與NPC照顧成本仍是既有簡化模型。

政策依據：[司法院婚姻與子女](https://www.judicial.gov.tw/tw/cp-105-58171-a547b-1.html)、[憲法法庭111年憲判字第8號](https://cons.judicial.gov.tw/docdata.aspx?fid=52&id=340546)及[離婚與子女親權調解聲請說明](https://www.judicial.gov.tw/tw/dl-140624-a7788dbbfb2f4565b03be89ec1f608b8.html)。經濟能力是因素之一，子女最佳利益不等於單純比較誰更有錢；扶養義務不因離婚消失。查閱2026-11-12。

## 壓力與疲勞滿值

18歲起任一數值到100，下一次推進會優先停在恢復事件；每月結算即使是年末最後一筆，也不能先越過滿值事件結年。不能用「繼續」或跳過來迴避選擇。

可選休息／請假、付費諮商加休息、免費支持、停止受僱／打工，或先休息再談婚姻。付費諮商需現金；免費恢復始終可選。自動模式優先休息，不會選擇離婚或辭職。辭職會清除現職與打工，後續月份不再發薪；過去薪資／帳目不回溯。此處沒有逐日假勤及法定請假扣薪模型。

角色欄顯示「近期來源」，保存最近四個增加該數值的事件標題；月結的工作、生活與照顧負擔採合併來源，不宣稱精確分解每一項壓力占比。舊存檔未記錄的原因明示「先前累積，原因未記錄」。這些數值與恢復效果是遊戲機制，不是健康診斷或諮商療效保證。

## 年紀與時間體感

| 年齡 | 新方向提示間隔 |
| --- | --- |
| 30歲以前 | 每年 |
| 30–39歲 | 每2年 |
| 40–49歲 | 每3年 |
| 50–59歲 | 每4年 |
| 60歲起 | 每5年 |

進入下一個十歲階段會重新規劃，因此39、49、59歲的計畫可縮短到下一個門檻。延續年份仍每年套用一次原方向、逐月記收入／保費／房租／扶養費、進行健康與死亡等事件，保留每年回顧，不直接把世界日期跳過數年。延續年份減少換屋、創業、興趣購物、旅遊目的地與在職求職等重複規劃卡；失業求職、畢業、升遷、重要家庭照顧、人格問答及滿值事件仍有機會出現。介面加入年歲漸長、轉眼一年過去的文字，這是使用者指定的敘事節奏，非心理學統計模型。
