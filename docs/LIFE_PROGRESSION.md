# v0.5 — 持續成長的工作、家庭與歷史區

2026-11-09。本版延續 v0.4，以下是已接入的遊戲規則；真實名稱、制度描述與未校準數值分開記錄。開局與資料說明保留估值告知，事件內不重複插入出戲的警語。

## 開局與姓名

網頁每次打開新人生設定都以 `crypto.randomUUID()` 產生新種子；種子藏在「進階：人生種子」，可手動指定重播。隨機性只在 UI 建立種子，人生引擎仍由該種子決定。既有 `createGame(seed, birthYear)` API 不改為非確定性。

姓名字典擴為 30 姓、80 個人工編寫名字，不是人口頻率資料。新生成父母完整姓名必定不同；舊存檔不改名。交往對象保留名字，成家不再重取同一人的名字；角色欄、伴侶訊息與關係事件顯示對象姓名。子女給六個穩定建議，可自訂名字，並選玩家或另一位家長的姓。僅接受已記錄的父母 ID，不可任意指定他人。

## 學習、樂器與升學

- 補習加入「全部五科」，各 +3，費用為五倍單科費；仍有免費讀書會。
- 無樂器紀錄、無音樂班／音樂社團背景者，不因年度專長目標就被強制排付費樂器事件。國高中有較精簡的音樂、運動及電影社；入社免費、不強制購樂器。大學仍有原本較多元的社團選擇。
- 樂器持有狀態持續保存，不每年重買。付費選項含老師到家、去音樂教室上課、學校練習及借用。持有四年後可自願更新，並非到期強制換購；舊檔沒有購買年時以最後付費年作保守參照。所有課費、設備價及學校借用權限為遊戲設定。成年畢業後停止自動主修安排。
- 會考保留五次 D20 與總分，另把每科 `min(100, (骰點＋熟練度)×5)` 換成 A/B/C，再顯示例如 `2A 2B 1C`。目前 A≥80、B≥40 為遊戲門檻，**不是官方答對題數標準**，也未計寫作與 ++／+ 標示。
- 大學「免試入學」讀取已保存的高中段考平均，不擲新 D20。舊檔沒有成績則以已存在熟練度計算參考值，會說明資料不足，不捏造歷史段考。
- 學測顯示國文、英文、數A、數B、自然、社會，各 0–15 級分。原有五個準備維度仍保留，數A/B暫共用數學檢定；換算 `round((D20+熟練度)×15/30)` 封頂15為遊戲公式，不是大考中心正式級距。分科暫同理顯示最高60級分，尚未建立完整分科考科與各校採計規則。
- 大學推薦仍是小型校系字典與遊戲難度排序，不是實際錄取率。
- 大學每學年記錄修課平均，保存在歷史區；這是學科能力加一次確定性年度波動的簡化成績，不是完整逐科學分系統。
- 碩班先選資訊工程／生命科學／企管／音樂，再選考試或在校成績申請。跨領域必須先做兩次先修準備（每次6,000），考試 DC21 高於相關領域 DC15；成績申請門檻跨域90、相關75，完全使用已保存的大學成績，不重擲骰。先修並不保證錄取。現階段研究所仍沿用原大學名稱作小型情境，完整各校研究所開設、先修課目與審查規則未建檔；無法宣稱每所大學都開設全部四領域。

制度來源：[會考等級及加註說明](https://cap-rcpet.rcpet.edu.tw/score3.html)、[會考常見問題](https://cap-rcpet.rcpet.edu.tw/qa.html)、[大考中心115統計說明](https://www.ceec.edu.tw/統計資料/說明會相關統計資料報告.pdf)。來源支持 A/B/C 及15級分制度，**不支持本遊戲的數值換算、門檻、機率或推薦公式**。

## 住宿、交通與自己的花費

有資料的校區與住家縣市相距遠時不提供住家選項，臺北／新北視為可通勤。這是簡化地區規則，未計實際車程；缺校區資料時不武斷禁止通勤。可申請每月3,000宿舍（D20分配）、租一般或便宜套房。宿舍未獲名額先安排9,000校外房，後續月租會記帳，資金不足仍進現有短缺負債流程；非真實宿舍申請承諾。

已有機車不再列購買同一台的選項。汽車另需駕照，可買25萬二手汽車，每月維護預留3,000。兩種車輛分開保存；尚未完整建模牌照／燃料稅、保險、折舊與駕駛事故分布。

朋友新增登山、露營、SUP、遊戲夜、書店市集及料理，依階段輪換，降低文具展與咖啡重複。成年可自選購露營裝備、PS5（2020起）、Nintendo Switch（2017起），已購不重複扣款。年份只作粗略可用性，未處理上市月份及各世代售價。費用為遊戲估值。高中伴侶的麥當勞約會可出現「後來都在親親我我，根本沒有讀到什麼」結語。

## 工作與創業

職涯字典擴為19個範例，新增台商、跨國公司與主管工作。更進階軟體職缺要求資訊領域背景及年資／已取得碩士學位；不是只看校名就保證好工作。已就業者不再列同公司同職位或較低薪的職缺。其他公司較高薪同職稱仍可應徵。每三年可作 D20 升遷評估；成功月薪+15%，更新職稱，失敗再累積三年。沒有雇用起年資料的極舊工作仍需先取得有紀錄的新職位。

本版國內職位每年12/20列一個月薪的年終，當年到職按月份比例；新增 Microsoft 範例不採固定年終。這是依需求配置的遊戲薪酬，**不是任何公司、國籍雇主或公教人員法定／實際政策**。薪資全為稅前；年終與正營運收入納入現有年度所得稅估列。新收入不是完整法定稅務試算。

來源支持職涯範例與職種，不支持月薪或個人錄取率：[趨勢職涯](https://www.trendmicro.com/zh_tw/about/careers.html)、[Microsoft臺北職涯](https://careers.microsoft.com/v2/global/en/locations/taipei.html)、[叡揚資訊](https://www.gss.com.tw/)。所有新月薪、D20難度、升遷間隔及調薪率是遊戲值。2026前真實雇主仍以泛稱顯示，未完整歷史化各企業與職務。

上班後朋友可提議雞排店、咖啡廳、酒吧、軟體接案、人力獵頭。啟動資金分別18萬、45萬、60萬、8萬、30萬；有足夠現金才可開始，接案需相關背景，獵頭需社交能力。D20及相關興趣決定初期營運，投入資金後離開正職、停止正職薪資，以每月淨營運收支入帳。年度可繼續調整或結束營業；可能虧損、產生短缺負債。課稅沿用簡化年度估列，尚無營業稅、公司設立／酒類許可、員工薪資、銷貨存貨及加盟合約模型。

## 成家、子女與父母

成家後可用180萬自備款買總價600萬住宅，餘420萬記房貸、每月還款20,000（原估值利率2%）。付自備款後停止該家庭租金；資產與房貸在家庭欄顯示。不允許無現金直接購買；房價、成數、利率與可買地區均未校準，不是房貸核准試算。

每名同住未成年子女都有每年照顧／學習安排及生病看診事件。奶粉尿布、伙食午餐、幼兒園、學雜書籍、制服、零用錢及選擇的補習／音樂課，逐月或逐學期入帳並附子女ID。零用錢同時記子女收款，消費不重複列兩次家長支出。

可選父母自行安排、在世健康祖父母、保母、公／私幼兒園；就學後選新／親戚二手制服、補習、音樂學習。調整一項後可繼續調整其他設定，補習與音樂可並存，最後選維持安排。升學年音樂路線另作D20，失敗保持普通班。這是輕量NPC教育，未完整模擬子女五科會考、各校音樂班名額與小孩自行選擇。

醫療自付先提供300或2,000的照護情境；不是實際療程或費率。每月資金不足可形成家長負債，不直接替小孩創建醫療負債。照顧選擇目前調整費用、疲勞與專長，尚未完整處理育嬰假、雙薪家庭工時、祖父母同意／距離、托育補助或臨床兒童疾病模型。

寒暑假成家玩家可安排附近郊遊、兩天一夜或出國，以同住在世人數計全團費，並留生活預備金；原生家庭旅遊仍自動旁白。新生兒出生當年自下次月結起有基本支出，細部照顧安排於下一年度提供。

父母NPC過世寫日期、疾病／意外死因及玩家記事。出生前已故父親也有死因；舊存檔未知死因保持未建檔，不編造過去。雙亡或無健康在世祖父母時不能選祖父母照顧，既有照顧設定自動回自己安排。疾病／意外是粗分類，死亡率仍未校準。

## 人格、帳本與存檔

在校與交友衝突可看見人格差異：偏獨處角色表達界線較困難，可免費找老師／朋友支持或先休息；不是聲稱內向必然被霸凌。原有互動、探索、規劃選項仍由人格光譜控制。

左側段考只留目前階段，每次再收折。已離開階段保存在「歷史區」；財務帳本及人生年表都可開啟。歷史分父母／家庭資助、個人實付與子女家庭開銷，各列年度明細及學習／伙食／衣物用品／醫療／生活比例。父母資助與被資助的實際消費不重複計為個人實付；學貸支應仍屬個人開銷，貸款撥款不是支出。混合奶粉尿布或制服書籍項目採文字主分類，尚未拆成精確商品單據。
